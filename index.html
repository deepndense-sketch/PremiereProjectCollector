Project Collector

Select or Ignore Medias for Backup

Green tracks are included. Single-click a track to fade it and ignore its media. Double-click one track, then double-click another track in the same group to ignore that full range. Media used on an ignored track will not be copied.

Nested sequence media is collected correctly even when a visible track count only reflects direct clips.

Premiere Project Folders

Only root bins are listed here. Bin buttons start neutral, meaning no special rule. Single-click once to turn green and force-copy that root bin, click again to fade it and ignore everything inside, click again to return it to neutral. Ignored bins win first; green bins force-copy only inside the reduced sequence and track selection. Double-click two bins to ignore the full range between them.

Root-level media that is not inside a Premiere folder will be copied into one CollectedMedias folder.

Source File List

Browse all source files by drive and folder. Selecting a drive or folder includes everything inside it. The list opens at the root only; expanding a folder shows just the next level.
